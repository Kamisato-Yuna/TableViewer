# 自动估算栏控制

2026-09-08。

设置中的“默认显示自动估算栏”使用持久化偏好，默认开启，修改后立即同步
到工作区。筛选栏前的按钮只改变当前工作区显示状态，不改写全局默认值；
切换表或连接保留临时选择，重新启动时采用全局默认值。

隐藏时不会发起自动浏览估算。已发出的请求可能继续完成，但返回结果不会
恢复隐藏栏。显示时按需估算；每次刷新、切表、重新显示均将详情收起。
数据浏览中的大规模提示展示于估算栏，不再自动打开确认弹窗。
