多语句按顺序执行，首次失败停止并保留先前结果。没有隐式批次事务；用户的 BEGIN/COMMIT/ROLLBACK 仍由数据库解释。自动提交的先前写入不会因为后续失败被撤回。失败后的显式事务状态须告知用户。

验证依次记录源代码/自动测试、各真实引擎、真实 .app 交互、最终签名分发物、线上 Release/更新/Pages。任何层级不得替代另一层级。只使用合成数据库与隔离脚本/Agent 设置，原应用数据和凭据保留。

## 已执行验证（2026-09-08）

自动与真实数据库检查使用隔离文件、脚本目录及专用 PostgreSQL 18.4 / MongoDB 7.0 实例，不使用个人数据库。运行环境为 Apple Silicon、macOS 27 beta、Xcode 27 beta 6；macOS 26 运行兼容性未在本轮确认。

- `test_workbench040.sh`：三引擎均执行，无跳过。覆盖写入阻止、预估不修改数据、元数据与复合外键、条件过滤、导出往返、多结果及失败停止、显式事务归属。PostgreSQL 只读查询使用独立短连接，以阻止临时对象等写入例外，不继承工作台事务和临时对象。
- `test_schema.sh`：SQLite 结构与关系、1005 个视图及 1005 列宽表完整读取；普通查询仍限制为 1000 行。
- `test_sql_scripts.sh`：脚本存储与 SQLite/PostgreSQL 字符串、注释、触发器、函数体边界。PostgreSQL 每条执行前重新读取字符串会话设置；多语句后续规模明确显示未知，因为前条语句可能改变对象或设置。
- `test_editor_and_pg_state.sh`：原生 AppKit 粘贴、SwiftUI 脚本切换生命周期、独立撤销栈、整行复制剪切菜单校验与撤销菜单路由，以及真实 PostgreSQL 字符串设置变化、BEGIN ATOMIC/CASE 和失败停止。
- `test_agent.sh`、`test_agent_workspace.sh`：协议、审批、结果共享、跨会话与跨连接隔离、历史恢复和未保存修改保护。合成协议服务不冒充真实模型验收。
- `test_databases.sh`、`test_reliability.sh`：SQLite 原有编辑、查询限制、失败恢复、退出保护；翻译检查包含 605 条中英文，更新清单测试 8 项通过。

真实 `.app` 中，MiniMax-M2.7 经 Chat Completions 工具调用完成 `SELECT 40 + 2`，手动批准后本地结果为 42，确认发送后模型完成续答。敏感审批模式自动执行常量 SELECT，并将建表停在等待批准；完全自动模式在独立示例库创建合成测试表。新会话保留旧会话的未发送结果，各模式均未自动共享查询结果。修复了真实工具卡片触发的辅助功能标签递归崩溃。

GUI 已观察到多语句预估确认、各条结果、失败详情、命名脚本及重启恢复、字段约束筛选、原始 DDL、真实外键关系与表名导航入口。表格验证了 Shift 连选、全选、双击单元格、空字符串与 NULL 独立编辑、批量删除确认及执行、只读锁提示、条件执行确认、JSON 实际文件导出。跨脚本重做、整行复制剪切及撤销、注释和选区快捷键均已执行；脚本默认 90 天清理保留未过期脚本。字体、字号、连字、浅色外观设置已生效；当前行高亮采用克制的系统标签色透明度。

Developer ID Application 正式包保持沙箱权限且不包含 get-task-allow。应用与 DMG 公证均获 Accepted，票据装订、Gatekeeper、只读挂载后的包内签名与版本均通过；DMG 更新签名已用包内公钥独立验证。正式 `.app` 在原应用容器启动成功，Studio 常量查询实际返回 42，PostgreSQL 与 MongoDB 测试连接均加载 10 个对象。没有修改已有数据库记录。

上下和左右原生分栏的尺寸调整均通过辅助功能接口验证；自动化鼠标拖动未产生可确认的位移，因此不计为拖动手势实测通过。其余 GUI 与自动测试覆盖范围按上文记录，不以分发验证替代交互验证。
