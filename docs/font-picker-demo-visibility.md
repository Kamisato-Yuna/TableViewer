# 字体下拉与示例数据库隐藏入口修复

基于 0.5.2 发布后的提交 d14562d，隔离分支 `codex/font-picker-demo-visibility`。不修改原工作目录保留的旧版未提交内容。

## 修改

- 编辑器字体由自由文本输入改为原生菜单 Picker，列出本机可加载的字体家族并保留 SF Mono 默认项。已有手工填写的字体名继续作为当前选项显示，不悄悄重置偏好；仍使用既有编辑器字体设置与回退逻辑。
- 示例隐藏状态本身能够持久化，缺陷在于隐藏按钮仅存在于一次性提示。用户选择继续显示、恢复示例或已有连接升级后，没有再次隐藏入口。现在只要存在非示例连接，“连接”标题旁的省略号菜单始终提供显示/隐藏操作，示例连接右键菜单也提供隐藏。不占用额外列表行，使用小号次要色图标，按用户反馈降低视觉强度。
- 隐藏仅影响侧栏可见性，不删除示例文件或连接，不强制切换正在查看的数据库。没有其他连接时禁用右键隐藏，保留移除最后一个非示例连接后自动显示示例的既有行为。
