# English store metadata

**Name**: TableViewer

**Subtitle**: Native database workspace

**Keywords**: database,SQLite,PostgreSQL,MongoDB,SQL,query,developer,CSV

**Description**:

Connect, explore, and edit data on your Mac. TableViewer is a native macOS workspace for SQLite, PostgreSQL, and MongoDB, with English and Simplified Chinese interfaces.

- Browse tables, views, collections, and schemas. Filter the current page and export loaded results to CSV.
- Run SQL or MongoDB JSON commands. Edit records with primary keys and Extended JSON documents.
- Inspect MongoDB replica-set topology and use the built-in JavaScript database shell.
- Optionally connect your own OpenAI-compatible service for help understanding schemas and writing queries. Each AI operation needs approval, and sharing results needs separate confirmation.
- Keep connection credentials in macOS Keychain, with App Sandbox enabled.

An editable SQLite sample database is included on first launch. Configure your own remote databases and optional AI provider. Requires an Apple Silicon Mac running macOS 26 or later. The built-in shell is not full mongosh and does not include Node.js or npm. SQL and shell writes affect the target database directly; use appropriate permissions and backups.

**What's new in 0.2.0**: English and Simplified Chinese interfaces and language settings, SQLite/PostgreSQL/MongoDB workflows, optional AI assistance, and MongoDB Shell.
