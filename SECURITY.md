# Security / 安全问题

请通过 GitHub 的 **Security → Report a vulnerability** 私下报告凭据泄露、数据越权、任意代码执行或未经确认的 AI 数据库操作。不要在公开 Issue 中发布密钥、真实数据库内容或可直接利用的细节。

Use **Security → Report a vulnerability** for private reports about credential exposure, unauthorized data access, code execution, or AI actions that bypass user approval. Do not publish secrets or private database records in an issue.

Include the app version, macOS version, affected database type, expected behavior, and a minimal reproduction using disposable data. This is a community project; no guaranteed response time is offered.

Only the latest published release receives fixes. SQL and MongoDB commands intentionally support writes. Always use an account with permissions appropriate to your work and retain database backups.
