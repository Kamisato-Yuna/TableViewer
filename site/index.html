使用前，了解当前范围 +

TableViewer 提供对象概览、真实外键关系、结构约束、本地多脚本与六类结果导出。当前未提供 SSH 隧道、SQL 自动补全、CSV 导入或多连接并行标签。快速文本筛选作用于当前页；条件模式经确认后在数据库执行。 导出范围为已加载结果；SQL INSERT 支持 SQLite 与 PostgreSQL。

Agent 助手需自行配置兼容 Chat Completions 的服务。内置 MongoDB Shell 覆盖常用交互，不包含完整 mongosh / Node.js 环境。当前未在 App Store 上架。
